# WILDQUEST 
Discover Kenya. Live the Adventure.

**WILDQUEST** is a travel website concept designed to showcase the beauty of Kenya and inspire visitors to explore its incredible destinations. The website provides a visually engaging experience where users can discover destinations, explore travel options, and view trip enquiry and contact page designs.

The project focuses on front-end web development, responsive layouts, and user interface design using HTML and CSS.

## Technologies Used

1. HTML5 — Page structure and content.
2. CSS3 — Styling, layouts, responsive design, and hover effects.
3. Font Awesome — Icons used throughout the interface.
4. Visual Studio Code — Code editor.
5. Git and GitHub — Version control and project hosting.
