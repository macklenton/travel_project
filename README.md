# WILDQUEST 
Discover Kenya. Live the Adventure.

**WILDQUEST** is a travel website concept designed to showcase the beauty of Kenya and inspire visitors to explore its incredible destinations. The website provides a visually engaging experience where users can discover destinations, explore travel options, and view trip enquiry and contact page designs.

The project focuses on front-end web development, responsive layouts, and user interface design using HTML and CSS.

## Project Overview

WILDQUEST is a Kenya-focused travel website concept designed to inspire exploration and showcase the country's diverse tourism destinations, from the iconic wildlife of Maasai Mara to the beautiful beaches of Diani and the scenic landscapes of Amboseli and Mount Kenya.

The project aims to provide visitors with an engaging and visually appealing platform where they can discover destinations, explore travel experiences, view trip enquiry options, and access contact information through a simple, user-friendly interface.

Inspired by Kenya's natural beauty, WILDQUEST combines destination photography, nature-inspired colours, structured layouts, and intuitive navigation to create a consistent digital travel experience.

The website is currently developed using HTML5 and CSS3 as a static front-end prototype. It demonstrates the design and structure of a potential travel platform, with opportunities for future expansion into a fully functional service.

## Technologies Used

1. HTML5 — Page structure and content.
2. CSS3 — Styling, layouts, responsive design, and hover effects.
3. Font Awesome — Icons used throughout the interface.
4. Visual Studio Code — Code editor.
5. Git and GitHub — Version control and project hosting.
  

## Project Goals

The primary goal of WILDQUEST is to design an attractive, accessible, and easy-to-navigate travel website that encourages users to discover Kenya's tourism destinations.

 ### The specific objectives are to:

- Promote Kenyan destinations: Present popular tourist attractions and natural landscapes through organised destination sections and photography.
- Improve user experience: Create clear navigation and consistent layouts that help visitors move between the homepage, exploration, booking, login, and contact pages.
- Support trip planning: Design a trip enquiry interface that demonstrates how visitors could communicate their travel preferences.
  
- Establish a consistent brand identity: Use a distinctive colour palette, typography, imagery, and reusable design elements.

## Business Rationale
**WILDQUEST** explores the idea of a digital platform that presents Kenyan travel opportunities in a clear, visually engaging, and organised way. By bringing destination discovery, trip enquiry information, and contact details together in one interface, the concept aims to reduce the effort visitors may experience when searching for travel inspiration.

From a business perspective, WILDQUEST could provide a foundation for a future travel-related service focused on:

Showcasing Kenyan destinations to local and international visitors.
Helping potential travellers identify destinations that match their interests.
Generating travel enquiries through a structured trip-planning interface.
